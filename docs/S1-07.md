# S1-07 — Quản lý bàn

Màn hình **Quản lý bàn** dành cho `QUAN_LY`: thêm/sửa bàn, lọc khu vực,
đổi trạng thái, sinh lại QR, tải PNG một bàn và PDF tất cả bàn trong khu vực.
Không xóa bàn; dùng `NGUNG_SU_DUNG` để giữ lịch sử.

## Quy ước dữ liệu

- `ma_ban`: duy nhất toàn nhà hàng, bỏ khoảng trắng đầu/cuối và chuyển chữ hoa.
- `khu_vuc_id`: khóa ngoại đến `khu_vuc`, không cho xóa khu vực còn bàn.
- Sức chứa là số nguyên: `1 <= suc_chua_toi_thieu <= suc_chua_toi_da`.
- `loai_ban`: `THUONG`, `PHONG_RIENG`.
- `trang_thai`: `TRONG`, `DANG_SU_DUNG`, `DA_DAT`, `NGUNG_SU_DUNG`.
- QR sinh bởi `secrets.token_urlsafe(32)`: 43 ký tự, không dựa trên mã bàn.
- `ban_qr_token` giữ mọi token đã phát hành. Khi đổi QR, cập nhật token hiện tại
  và thêm lịch sử trong cùng transaction, khóa hàng bàn để tuần tự hóa yêu cầu.
- Quét QR không yêu cầu đăng nhập: hiện tại trả 200; đã đổi trả 410 với thông báo
  “Mã QR đã thay đổi”; không tồn tại trả 404; bàn/khu vực ngừng sử dụng trả 409.
- Sửa thông tin bàn không đổi QR. PNG/PDF chứa URL `QR_FRONTEND_URL/?qr=<token>`.
- PDF gồm tất cả bàn thuộc khu vực, kể cả bàn ngừng sử dụng, 6 QR/trang.
  Khu vực rỗng trả 404. Font DejaVu được cài trong image để hỗ trợ tiếng Việt.

## Kiểm tra API bằng PowerShell

Các lệnh sau tạo khu vực và bàn thử trong database ứng dụng. Dùng tài khoản
quản lý hiện có; tài khoản dưới đây là demo mặc định khi chưa thay đổi mật khẩu.

```powershell
$base = 'http://localhost:8000'
$login = @{identifier='manager'; password='demo12345'} | ConvertTo-Json
Invoke-RestMethod "$base/api/auth/login" -Method Post -ContentType 'application/json' -Body $login -SessionVariable session

$suffix = Get-Date -Format 'yyyyMMddHHmmss'
$areaBody = @{ten_khu_vuc="S107-$suffix"; thu_tu_hien_thi=0} | ConvertTo-Json
$area = Invoke-RestMethod "$base/api/khu-vuc" -Method Post -WebSession $session -ContentType 'application/json' -Body $areaBody
$payload = @{ma_ban="B-$suffix"; khu_vuc_id=$area.id; suc_chua_toi_thieu=2; suc_chua_toi_da=6; loai_ban='THUONG'; trang_thai='TRONG'}
$table = Invoke-RestMethod "$base/api/ban" -Method Post -WebSession $session -ContentType 'application/json' -Body ($payload | ConvertTo-Json)

Invoke-RestMethod "$base/api/ban?khu_vuc_id=$($area.id)" -WebSession $session
$payload.suc_chua_toi_da = 8
Invoke-RestMethod "$base/api/ban/$($table.id)" -Method Put -WebSession $session -ContentType 'application/json' -Body ($payload | ConvertTo-Json)

$oldToken = $table.qr_token
Invoke-RestMethod "$base/api/ban/qr/$oldToken"
$table = Invoke-RestMethod "$base/api/ban/$($table.id)/qr/regenerate" -Method Post -WebSession $session

# Mong đợi 410 và thông báo mã đã thay đổi (PowerShell hiển thị lỗi HTTP).
try { Invoke-RestMethod "$base/api/ban/qr/$oldToken" } catch { $_.ErrorDetails.Message }
Invoke-RestMethod "$base/api/ban/qr/$($table.qr_token)"

Invoke-WebRequest "$base/api/ban/$($table.id)/qr.png" -WebSession $session -OutFile 'ban-qr.png'
Invoke-WebRequest "$base/api/ban/khu-vuc/$($area.id)/qr.pdf" -WebSession $session -OutFile 'khu-vuc-qr.pdf'

# Mong đợi 409 vì mã bàn trùng.
try { Invoke-RestMethod "$base/api/ban" -Method Post -WebSession $session -ContentType 'application/json' -Body ($payload | ConvertTo-Json) } catch { $_.ErrorDetails.Message }

# Mong đợi 422 vì sức chứa không hợp lệ.
$payload.suc_chua_toi_da = 1
try { Invoke-RestMethod "$base/api/ban" -Method Post -WebSession $session -ContentType 'application/json' -Body ($payload | ConvertTo-Json) } catch { $_.ErrorDetails.Message }

# Mong đợi 401 khi không có phiên đăng nhập.
try { Invoke-RestMethod "$base/api/ban" } catch { $_.ErrorDetails.Message }
```

Swagger: http://localhost:8000/docs. Kiểm tra UI: tạo/sửa bàn, chọn khu vực,
tải PNG/PDF, mở URL trong QR trước và sau khi sinh lại.

## Quét từ điện thoại cùng mạng LAN

Đặt các biến sau trong `.env` tại thư mục gốc, thay IP bằng IP máy chạy Docker:

```dotenv
QR_FRONTEND_URL=http://192.168.1.10:5173
FRONTEND_URLS=http://localhost:5173,http://127.0.0.1:5173,http://192.168.1.10:5173
VITE_API_BASE_URL=http://192.168.1.10:8000
VITE_WS_BASE_URL=ws://192.168.1.10:8000
```

Chạy lại `docker compose up -d --build`, tải lại PNG/PDF để URL mới được đưa
vào ảnh. `localhost` trên điện thoại trỏ về chính điện thoại.

Thư viện: [qrcode](https://pypi.org/project/qrcode/) để sinh PNG và
[ReportLab TrueType fonts](https://docs.reportlab.com/reportlab/userguide/ch3_fonts/)
để nhúng font tiếng Việt vào PDF.

Tại thời điểm rà soát, container backend đang chạy vẫn dùng image cũ, OpenAPI
không có `/api/ban`. Các test ở trên chạy bằng image mới trong container tạm.
Chưa thay container phục vụ ứng dụng và chưa migrate database ứng dụng trong lần
rà soát này. Chạy lệnh triển khai ở trên rồi kiểm tra:

```powershell
docker compose exec backend alembic current
$schema = Invoke-RestMethod 'http://localhost:8000/openapi.json'
$schema.paths.PSObject.Properties.Name | Where-Object { $_ -like '/api/ban*' }
```

Mong đợi revision `003_add_ban` và 6 đường dẫn `/api/ban...` (8 operation).
Các route có token chỉ kiểm tra thông tin bàn khi mở trang; trang đã mở trước
khi đổi QR không tự cập nhật. Khi nghiệm thu cần quét lại hoặc tải lại trang.

Checklist test tay bắt buộc trước khi đánh dấu hoàn tất trên web/điện thoại:

1. Đăng nhập quản lý, thêm/sửa bàn, mã trùng, sức chứa sai, lọc khu vực và đổi trạng thái.
2. Tải PNG và PDF bằng nút giao diện, mở file, kiểm tra tiếng Việt và tất cả bàn.
3. Dùng điện thoại cùng LAN, cấu hình URL như trên; quét QR mới không cần đăng nhập.
4. Sinh lại QR, quét lại ảnh cũ để thấy thông báo mã đã thay đổi; tải ảnh mới và quét thành công.
5. Quét QR từ PDF/bản in để xác nhận độ rõ và đúng bàn. Chưa có test tự động giải mã ảnh QR.
